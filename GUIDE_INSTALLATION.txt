============================================================
 ETAPE 1 : INSTALLER XAMPP
============================================================

WINDOWS :
  1. Telecharger XAMPP depuis : https://www.apachefriends.org
  2. Installer (laisser les options par defaut, cocher Apache + MySQL + PHP)
  3. Le dossier d'installation sera : C:\xampp
  4. Lancer XAMPP Control Panel
  5. Cliquer "Start" sur Apache et MySQL (les deux doivent etre verts)

MAC :
  1. Telecharger XAMPP depuis : https://www.apachefriends.org
  2. Installer normalement
  3. Le dossier sera : /Applications/XAMPP/xamppfiles/
  4. Lancer XAMPP et demarrer Apache + MySQL

============================================================
 ETAPE 2 : COPIER LE PROJET
============================================================

WINDOWS :
  1. Dezipper le fichier .zip
  2. Copier le dossier dans : C:\xampp\htdocs\
     Exemple : C:\xampp\htdocs\PROREJCTWEB1\
  3. Verifier que le dossier contient : config.php, Controllers/, Models/, Views/

MAC :
  1. Dezipper le fichier .zip
  2. Copier dans : /Applications/XAMPP/xamppfiles/htdocs/
     Exemple : /Applications/XAMPP/xamppfiles/htdocs/PROREJCTWEB1/

============================================================
 ETAPE 3 : CREER LA BASE DE DONNEES
============================================================

  1. Ouvrir le navigateur et aller sur : http://localhost/phpmyadmin
  2. Cliquer sur "Nouvelle base de donnees" (ou "New") a gauche
  3. Nom de la base : freelence_hub
  4. Interclassement : utf8mb4_unicode_ci
  5. Cliquer "Creer"

============================================================
 ETAPE 4 : IMPORTER LES TABLES SQL
============================================================

  1. Dans phpMyAdmin, cliquer sur la base "freelence_hub" a gauche
  2. Cliquer sur l'onglet "Importer" en haut
  3. Cliquer "Parcourir" et selectionner le fichier : database/schema.sql
  4. Cliquer "Executer"
  5. Ensuite importer aussi : database/seed_admin.sql (pour le compte admin)

 PROBLEMES FREQUENTS
============================================================

  PROBLEME : "Page blanche" ou erreur 500
  SOLUTION : Verifier que Apache et MySQL sont bien demarres dans XAMPP

  PROBLEME : "Table doesn't exist"
  SOLUTION : Reimporter schema.sql dans phpMyAdmin

  PROBLEME : "Access denied for user 'root'"
  SOLUTION : Le mot de passe MySQL par defaut dans XAMPP est vide.
             Verifier dans config.php que DB_PASS = ''

  PROBLEME : Les donnees ne s'affichent pas apres ajout
  SOLUTION : Faire un rafraichissement force : Ctrl+Shift+R (Windows)
             ou Cmd+Shift+R (Mac)

  PROBLEME : "Connection refused" sur localhost
  SOLUTION : 
    Windows : Verifier que le port 80 n'est pas utilise par Skype ou autre
              Dans XAMPP > Config > Apache > changer le port si necessaire
    Mac     : Meme chose, ou utiliser le port 8080

      ├── projets/            ← Module Projets (Ilyes)
      └── experience/         ← Module Experience (Yassine)
